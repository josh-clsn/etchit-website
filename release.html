Install // pick your platform

The release artifacts live on the GitHub Releases pages for each app. While the apps are private (josh-clsn/*), grab via gh release download — once they go public on etchit-io/*, swap to plain curl.

fetch>it desktop — Linux .deb

# Ubuntu / Debian / Mint
gh release download v0.2.7 \
  --repo josh-clsn/fetchit \
  --pattern "fetchit_*_amd64.deb" \
  --dir /tmp --clobber
sudo apt install -y /tmp/fetchit_0.2.7_amd64.deb

Fresh-install reset

If you've installed an older build and want a clean slate (drops your wallet / history / bookmarks / settings):

# Linux
sudo apt remove etchit fetchit
rm -rf ~/.local/share/io.etchit.desktop ~/.local/share/io.etchit.fetchit

# macOS
rm -rf /Applications/etchit.app /Applications/fetchit.app
rm -rf ~/Library/Application\ Support/io.etchit.desktop ~/Library/Application\ Support/io.etchit.fetchit

# Windows (PowerShell, admin)
Get-Package -Name "etchit","fetchit" | Uninstall-Package
Remove-Item -Recurse -Force "$env:APPDATA\io.etchit.desktop","$env:APPDATA\io.etchit.fetchit"

What's new // since v0.2.3 / v0.2.8

QR share modal — unified across desktop & Android

  • Editable title field below the QR, pre-filled from the caller's label (etch title, page <title>, bookmark label, screenshot filename) and overridable before exporting. Empty title → no title row on the saved card.
  • Abbreviated address on a single line — <first8>…<last8>. Full hex stays inside the QR and on the clipboard buttons.
  • 4-button 2×2 action grid — address, autonomi://…, save image, copy image. Short labels so the row no longer wraps on narrow phones.
  • Save image / Copy image both export the full branded card (wordmark + QR + title + address + footer) — not the bare QR.
  • Copy image goes through a single Rust command (copy_png_to_clipboard) — decodes via the png crate and writes RGBA in one frame. The earlier JS-side two-hop chain dropped resource handles on webkit2gtk.
  • Spec for iOS authors lives in docs/QR-SHARE.md on the fetchit repo.

etch/it desktop

  • History tab → Share QR button on every row, pre-fills with the stored label.
  • Screenshot toast persistence — dismissed fingerprints survive app restarts (file-backed, not localStorage which silently lost the write when you closed the app fast). One prompt per unique image, period.
  • The screenshot watcher now suppresses its next poll when you copy a QR from inside etch/it — no more "etch this image?" on your own QR.
  • Resume banner hides during an active finalize so it doesn't compete with the upload in flight.
  • Support address is in Settings → just below Peers.

etch/it Android

  • Same QR share modal as desktop, mirrored layout.
  • Wallet error sanitisation — the WalletConnect bridge's [object Object] artifact now surfaces as "wallet didn't respond — try again".
  • Save image announces destination via toast.

fetch>it

  • JSON-handler false positive fixed. Plain text starting with t, f, or n (e.g. anything beginning with "the", "no", "test") used to get claimed by the JSON dispatcher and fail rendering with "couldn't reach this content". Detector now only claims { / [ starts.
  • CLI: fetchit get <addr> now previews HTML renditions.
  • Android FFI rebuilt so the JSON fix is actually in the APK — gradle alone doesn't trigger a Rust rebuild.

fetchit-city demo

  • v1.5 cut. Now at autonomi://ba9a8fca…ec94e764 — bumped to include @aatonnomicc's Compound Calculator in the community spoke alongside Battleships, hi/lo, and Saloon Showdown.
  • QR card on etchit.io's landing page regenerated as a full branded export card so the artifact on the marketing site carries the same visual language as the apps' own QR exports.

etchit.io

  • Email aliases live — support@, privacy@, hello@, press@, reports@ all forward to the project inbox via Cloudflare Email Routing.
  • DNS migrated to Cloudflare; GitHub Pages still serves the apex (DNS-only, not proxied).
  • New /release.html (this page) and /privacy.html, /eula.html from the iOS TestFlight prep.

Test plan // tick each on a fresh install

Aim for a clean run on a freshly-installed copy with no carried-over settings. Always test the golden path first, then poke the edges.

QR share — across all four apps

  1. Open the QR modal anywhere it's exposed (header ▦ on fetch>it desktop, Ctrl+Shift+S, etch result row, history row, blog publish, bookmark long-press on mobile). Modal opens; title input visible; address row reads <8>…<8> on one line.
  2. Type a custom title → Save image → native save dialog appears → save → exported PNG shows wordmark + QR + your typed title + abbreviated address + footer.
  3. Clear the title → Save image again. Exported PNG has no title row, address sits flush below the QR.
  4. Copy image → paste into any chat or image viewer. Same branded card lands.
  5. Copy address → paste anywhere. 64-hex lowercase, nothing else.
  6. Copy autonomi://… → paste. Full URL form.
  7. Scan the QR with a phone camera. Phone deep-links into fetch>it.

etch/it desktop — screenshot toast

  1. Enable the toggle in Settings → Screenshot prompts.
  2. Take a screenshot (Linux: copy via Flameshot etc; macOS: Cmd+Shift+Ctrl+4; Windows: Snipping Tool → Copy). Toast appears within ~3 s with the preview.
  3. Dismiss the toast any way you like — explicit button, close window, alt-tab — then relaunch etch/it. Same screenshot does not re-prompt.
  4. Inside the QR modal, click Copy image. No "etch this image?" prompt for your own QR.

etch/it Android — wallet errors

  1. Start an etch that needs a wallet signature. Take the prompt past the WalletConnect timeout (30 s+ no action). Error message reads "wallet didn't respond — try again", not [object Object].

fetch>it Android — JSON-detector fix

  1. On etch/it mobile, etch a short text starting with "the" or "no" or "test".
  2. Copy the returned address, paste it into fetch>it Android. Renders as plain text, not "couldn't reach this content".

Demo city v1.5

  1. Scan the QR on etchit.io with your phone camera (or paste autonomi://ba9a8fcae5677af1876de8b37b1f728446754b6fe78307c2355be28cec94e764). Front-door page loads.
  2. Navigate to community → confirm the Compound Calculator tile is present alongside Battleships / hi/lo / Saloon Showdown. Tap → it opens, no white-screen / sandbox errors.

Known issues // shipped warts

Signed Android APKs aren't generated by the josh-clsn forks — the KEYSTORE_BASE64 secret only exists on the public etchit-io mirrors. Promote the tag to public to get a signed build.
iOS build is in flight against the same docs/QR-SHARE.md spec. TestFlight invite goes out separately when ready.
Cross-app screenshot suppression. If fetch>it desktop and etch/it desktop are open at the same time and you copy a QR from fetch>it, etch/it's clipboard watcher will catch it once. Click Dismiss; the fingerprint persists and it won't repeat for that exact QR. (Cross-process suppression is on the wishlist if this actually annoys testers.)
